# Sprint #6 - Bloqueo Rápido por PIN

**Proyecto:** Financiero
**Fecha:** 22/04/2026

## Objetivo

Permitir al usuario bloquear rápidamente su cuenta mediante un PIN de seguridad utilizando la autenticación por token.

## Funcionalidades

* Bloqueo rápido de la cuenta desde la aplicación.
* Validación del PIN de seguridad antes de realizar el bloqueo.
* Verificación de la identidad del usuario mediante token JWT.
* Asociación del bloqueo a la cuenta autenticada.
* Registro de fecha y hora del bloqueo.
* Notificación al usuario sobre el estado del bloqueo.

## Reunión de Planificación

| Descripción                               | Tiempo |
| ----------------------------------------- | ------ |
| Definición de cantidad de dígitos del PIN | 10 min |
| Validación mediante token JWT             | 10 min |
| Implementación de bloqueo de cuenta       | 10 min |

## Criterios de Aceptación

* El usuario debe estar autenticado mediante token JWT.
* El PIN debe cumplir con la longitud definida por el sistema.
* La cuenta debe quedar bloqueada inmediatamente después de la validación correcta.
* Debe registrarse el evento de bloqueo en la base de datos.
* El usuario debe recibir una notificación de confirmación.

## Tecnologías Relacionadas

* FastAPI
* JWT (JSON Web Token)
* MySQL
* React Native
